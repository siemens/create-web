# Siemens Create Web

[![MIT License](https://img.shields.io/badge/license-MIT-009999.svg?style=flat)](./LICENSE)

Starter templates for Element/iX open-source design system. This repository provides ready-to-use starter apps that can be scaffolded with [`npm-init
`](https://docs.npmjs.com/cli/v12/commands/npm-init).
